# Portfolio Redesign Research

Riset ini mendokumentasikan tiga referensi visual untuk portfolio `my-portfolio`. Tahap ini tidak mengubah kode aplikasi, aset, dependensi, konfigurasi, Git state, atau `DESIGN.md`.

## Dokumen
- `reference-01-rifki.md`: atmosfer sinematik, loader, hero, tech marquee, timeline, preview sertifikat.
- `reference-02-zahidan.md`: About, project grid, halaman detail proyek, galeri, tema, footer.
- `reference-03-fadhil.md`: aksen editorial, border berlapis, theme toggle, pola modal sertifikat.
- `cross-reference-synthesis.md`: arah desain dan persyaratan target.

**Status bukti:** temuan yang tidak berhasil diuji langsung ditandai sebagai belum terverifikasi. Nilai visual referensi bukan token final yang wajib disalin.

**Keputusan target:** Experimental Editorial Hybrid; detail proyek memakai halaman/rute tersendiri, bukan modal; modal khusus detail sertifikat; light/dark mode menyimpan preferensi. `DESIGN.md` dan kode menunggu tahap serta persetujuan berikutnya.
